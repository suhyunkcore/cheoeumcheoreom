처음은 처음처럼 모바일 웹사이트

1. 폴더 안의 index.html을 더블클릭하면 실행됩니다.
2. GitHub Pages에 올릴 때 폴더 안의 파일 전체를 저장소 최상위에 업로드하세요.
3. 질문/게임 문구는 app.js의 friendGames, coupleQuestions 배열에서 수정할 수 있습니다.
4. 디자인은 제공한 3장의 이미지를 화면 배경으로 사용해 원본과 최대한 동일하게 구현했습니다.
5. 클릭 영역:
   - 메인 상단 카드: 연인처럼
   - 메인 하단 카드: 친구처럼
   - 상세 화면 왼쪽 상단: 뒤로가기
   - 상세 화면 하단 버튼: 랜덤 문구 변경
